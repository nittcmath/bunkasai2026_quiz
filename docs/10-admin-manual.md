# 管理者マニュアル

## ログイン

- `/admin` にアクセスする
- 管理者パスワードを入力する
- Cookie ベースの短期トークンで管理画面に入る

## 主な操作

- ユーザー検索: visitorId / ニックネーム検索
- 問題管理: 追加・編集・削除
- 模擬店管理: 追加・編集
- ランキング再計算: 不整合時に実行
- ポイント手動付与/減算: 迷子復旧時に使用
- CSV 出力: Users / Answers / Exchanges

## 注意点

- 正答判定の直接編集は避ける
- 交換トークンは必ず現地で短命運用する
- 受付担当は景品名と必要ポイントを二重確認する
