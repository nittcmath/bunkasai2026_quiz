# セキュリティ設計書

## 対策

- visitorId は UUIDv4 で生成する
- Cookie は HttpOnly / SameSite=Lax / 365 日
- 点数計算と正誤判定はサーバー側のみ
- 問題点数をクライアントから送信しない
- 交換 QR は 60 秒失効、1 回のみ使用
- 管理 API はパスワードベースの短期トークンで保護する
- 連続アクセスには簡易レートリミットを適用する
- 入力値は trim と正規化を行う

## 想定脅威

- Cookie 改ざん
- 交換トークン使い回し
- 正答値のクライアント改ざん
- 管理画面の不正アクセス
- XSS / CSRF

## 実装方針

- サーバー側のみで判定する
- 管理者パスワードは Script Properties に保存する
- ログは AdminLogs に追記する
