# テスト仕様書

## 機能テスト

- visitorId がない初回アクセスで Cookie が生成される
- /booth/[boothId] で訪問履歴が保存される
- /question/[questionId] で問題閲覧履歴が保存される
- 初回回答時にニックネーム登録導線が出る
- 正解時のみポイントが加算される
- 同一問題の再正解で加点されない
- ランキングが総獲得ポイント順で並ぶ
- 景品交換が 60 秒トークンでのみ成功する

## セキュリティテスト

- CSRF 無し POST が拒否される
- 失効済みトークンが拒否される
- 使い回しトークンが拒否される
- 管理者認証無しで /admin 系 API が拒否される

## 受入テスト

- モバイル表示で主要導線が 1 画面内に収まる
- ホームで状態が確認できる
- マイページで履歴が確認できる
